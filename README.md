A **full-stack job posting platform** where companies can post jobs 🏢 and candidates can apply 📄 with resume upload.  
Built using **React.js**, **Node.js**, **Express.js**, and **MongoDB**, with **email notifications** for all key actions.

---

## Live : [https://codsoft-job-board-web-fwek.onrender.com]

## ✨ Features

### 👨‍💼 For Candidates
- 🔍 **Browse & Search** jobs by title/keywords  
- 📄 **View Job Details** with complete description  
- 📤 **Apply for Jobs** with resume upload  
- 📑 **Track Applications** in *My Applications* page  
- 📩 Email confirmation after applying  

### 🏢 For Companies
- ➕ Post new job openings  
- 👀 View candidate applications  
- 📬 Receive notifications for new applications  

### 🌐 Common
- 📞 Contact form to reach Job Board team  
- ✉️ Email alerts for:  
  - Job applications  
  - New job postings  
  - Contact form submissions

2️⃣ Backend Setup

cd Backend
npm install
npm start


3️⃣ Frontend Setup

cd Frontend
npm install
npm run dev



4️⃣ Environment Variables
Create a .env file in Backend folder:

MONGO_URI=your_mongodb_connection_string
PORT=5000
EMAIL_USER=your_email@example.com
EMAIL_PASS=your_email_password
